# DevCraft

### A Guided MERN Stack Learning Platform & Developer Community

DevCraft is a web-based learning platform designed to help aspiring developers improve their MERN stack skills through guided coding projects, interactive lessons, debugging challenges, a developer community, and mentorship.

## My Contribution

**Developer:** Dinisuru P.W.L.  
**Project Group:** DoD  
**Assigned Module:** Hybrid Mentorship Ecosystem & Discount Rewards Engine

My responsibilities cover four main features:

### 1. AI Mentor & Coin System
- Provide AI-powered assistance for coding questions and debugging.
- Allocate free daily coins for AI mentor requests.
- Track coin balances and usage.
- Support purchasing additional coins.

### 2. Human Mentorship Marketplace
- Display verified mentors and their profiles.
- Let learners check mentor availability.
- Allow learners to book one-on-one mentoring sessions.

### 3. Payment Integration
- Integrate PayHere for secure payment processing.
- Handle payments for mentor bookings.
- Support AI coin top-up payments.

### 4. Discount Rewards Engine
- Connect leaderboard rankings with discount rewards.
- Calculate eligible discounts for platform services.
- Apply applicable rewards during checkout.

## Technologies

- **Backend:** Node.js, Express.js
- **Database:** MongoDB
- **AI Integration:** OpenAI / LLM API
- **Payment Gateway:** PayHere
- **Platform:** MERN Stack (MongoDB, Express.js, React.js, Node.js)
